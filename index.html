    메모

    떠오른 생각을 적어 두는 곳이에요. 원고 분량에는 들어가지 않아요.

      원고 파일에 자동 저장

      원고 불러오기

      워드(.docx)나 텍스트(.txt) 파일을 고르면 새 장으로 추가돼요. 지금 쓰던 원고는 지워지지 않아요.

      • 워드 문서의 ‘제목 1’ 스타일 문단이 있으면 그 단위로 장을 나눠요.
      • 텍스트 파일은 # 장 제목처럼 #으로 시작하는 줄에서 장을 나눠요.
      • 한글(hwp) 파일은 한글 프로그램에서 다른 이름으로 저장 → 파일 형식 ‘워드 문서(*.docx)’로 바꾼 뒤 불러오세요.

      백업 파일로 되살리기

      ‘내보내기 → 전체 백업’으로 저장한 .json 파일을 고르면, 지금 이 브라우저의 원고·표기 사전·설정을 백업 내용으로 바꿔요.

      내보내기

      형식
      범위

      파일은 내 컴퓨터(휴대폰)의 ‘다운로드’ 폴더에 저장돼요. 원고는 이 브라우저에만 있으니 자주 내보내 두세요.

      내 표기 사전

      인물 이름, 외래어, 책에서 정한 용어를 적어 두면 다르게 쓴 곳을 찾아 줘요. 여러 개는 쉼표(,)로 나눠 쓰세요.

      쓰는 법

      1. 쓰기 — 왼쪽에서 장을 고르고 가운데에 원고를 쓰세요. 쓰는 대로 이 브라우저 안에 자동 저장돼요. 인터넷으로 보내지 않아요.
      2. 점검 — 잠시 손을 멈추면 오른쪽에 점검 결과가 나와요. 원고에서 색칠된 곳이 지적된 곳이에요.
        • 고치기 권장 거의 확실히 틀린 표기예요. 적용을 누르면 고쳐져요.
        • 확인 필요 문맥에 따라 맞을 수도 있어요. 설명을 읽고 직접 판단하세요.
        • 참고 틀린 건 아니지만 문장을 다듬을 때 참고할 점이에요.
        맞는데 지적됐다면 무시를 누르세요. 같은 곳은 다시 지적하지 않아요.
      3. 애매할 때 — 지적 카드의 Claude에 물어보기를 누르면 질문이 복사돼요. claude.ai에 붙여 넣으세요.
      4. 보관 — 컴퓨터의 크롬·엣지라면 원고 파일 → 새 원고 파일 만들기를 한 번 해 두세요. 그다음부터는 쓰는 대로 그 파일에 자동 저장돼요. 구글 드라이브·원드라이브 폴더에 만들면 자동 백업까지 돼요. 다른 브라우저나 휴대폰에서는 원고가 그 브라우저에만 있으니 내보내기로 자주 파일을 받아 두세요.
      5. 휴대폰 메모 — 휴대폰과 컴퓨터는 저장 공간이 따로예요. 휴대폰에서 쓴 메모는 내보내기 → 텍스트로 저장한 뒤, 컴퓨터에서 불러오기 → 메모로 불러오기로 옮기세요.

      이 도구는 규칙으로 흔한 실수를 찾을 뿐, 모든 오류를 잡지는 못해요. 잘못 고치는 것보다 놓치는 쪽을 택했어요. 출간 전에는 사람의 교정을 한 번 더 받는 것을 권해요.
