# 책 원고 교정기

책을 쓰면서 스스로 교정할 수 있는 **무료** 웹 도구예요. 서버도, 회원가입도, 유료 API도 없이 **브라우저 안에서만** 돌아가요.
원고는 내 브라우저에만 저장되고 인터넷으로 보내지 않아요.

## 여는 법

- **인터넷 주소로 열기** (GitHub Pages를 켠 뒤): `https://ungmung.github.io/book-editor/`
- **내 컴퓨터에서 바로 열기**: 이 저장소를 ZIP으로 내려받아 압축을 풀고 `index.html`을 더블클릭하세요.

> 주의: 원고는 **그 브라우저 안**에 저장돼요. 다른 브라우저, 다른 기기, 시크릿 창에서는 보이지 않아요.
> 컴퓨터를 바꾸거나 브라우저 기록을 지우기 전에는 꼭 **내보내기**로 파일을 받아 두세요.

## 할 수 있는 것

| 기능 | 내용 |
|---|---|
| 장별 편집 | 장 추가·이름 바꾸기·순서 바꾸기·삭제, 메모 칸(분량에 안 들어감), 자동 저장 |
| 맞춤법 | 되/돼, 안/않, 로서/로써, 몇일→며칠, 어떻해→어떡해, 왠/웬, -ㄹ께→-ㄹ게, 이였다→이었다 등 70여 가지 |
| 띄어쓰기 | 의존명사 수·것·데·만큼·뿐·듯·때문 (확실한 형태만) |
| 문장부호 | 따옴표 짝, 마침표 중복, 문장부호 앞뒤 빈칸, 말줄임표·따옴표 모양 통일 |
| 문장 다듬기 | 긴 문장, 한 문단 안 같은 낱말 반복, 같은 끝맺음 반복, 번역투(~것이다, ~에 있어서, ~을 가지다, ~에 의해, 이중 피동 등) |
| 표기 통일 | 내 표기 사전(인물 이름·외래어·용어)과 다르게 쓴 곳, 자주 틀리는 외래어 약 70개 |
| 통계 | 글자 수(공백 포함·제외), 200자 원고지 매수(근사값), 장별 분량 |
| 파일 | 워드(.docx)·텍스트(.txt) 내보내기·불러오기, 전체 백업(.json) |

각 지적은 세 단계로 나뉘어요.

- **고치기 권장** — 거의 확실히 틀린 표기. ‘적용’을 누르면 고쳐져요(Ctrl+Z로 되돌리기).
- **확인 필요** — 문맥에 따라 맞을 수도 있어요. 설명을 읽고 판단하세요.
- **참고** — 틀린 건 아니지만 문장을 다듬을 때 참고할 점.

잘못 고치는 것보다 놓치는 쪽을 택했어요. 모든 오류를 잡지는 못하니, 출간 전에는 사람의 교정을 한 번 더 받는 걸 권해요.
애매한 문장은 지적 카드의 **Claude에 물어보기**를 눌러 질문을 복사한 뒤 claude.ai에 붙여 넣으세요.

## 한글(hwp) 파일

hwp는 형식이 공개돼 있지 않아 브라우저에서 바로 읽고 쓸 수 없어요.

- 불러올 때: 한글 프로그램에서 **다른 이름으로 저장 → 워드 문서(*.docx)** 로 바꾼 뒤 불러오세요.
- 내보낸 .docx는 한글 프로그램에서 그대로 열려요.

## 휴대폰에서 쓴 메모 옮기기

휴대폰과 컴퓨터는 저장 공간이 따로예요.
휴대폰에서 **내보내기 → 텍스트**로 저장하고, 컴퓨터에서 **불러오기 → ‘메모로 불러오기’ 체크** 후 파일을 고르세요.

## 개인정보와 공개 저장소

이 저장소는 공개 저장소예요. **원고 파일을 이 폴더에 넣거나 커밋하지 마세요.**
`.gitignore`가 .docx, .txt, .hwp, 백업 .json 파일을 커밋에서 빼 주지만, 원고는 이 폴더 밖에 두는 게 가장 안전해요.

## GitHub Pages로 올리기 (무료)

1. GitHub에서 이 저장소의 **Settings → Pages**로 가요.
2. **Source**를 ‘Deploy from a branch’, **Branch**를 `main` / `/ (root)`로 고르고 Save를 눌러요.
3. 1~2분 뒤 `https://ungmung.github.io/book-editor/` 에서 열려요.

## 개발자용

```
node tests/rules.test.js                 # 교정 규칙 테스트 (예문만 사용)
python3 -m http.server 8765 &            # 로컬 서버
node tests/e2e.js                        # 브라우저 동작 테스트 (Playwright)
```

| 파일 | 역할 |
|---|---|
| `js/rules.js` | 교정 규칙 엔진 (규칙 추가는 여기서) |
| `js/docx.js` | 외부 라이브러리 없이 docx 만들기·읽기 |
| `js/storage.js` | IndexedDB 자동 저장 |
| `js/stats.js` | 글자 수·원고지 매수 |
| `js/app.js` | 화면 동작 |
